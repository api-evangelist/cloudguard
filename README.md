Check Point CloudGuard is a Cloud Native Application Protection Platform (CNAPP) delivering cloud security posture management (CSPM), cloud workload protection (CWPP), code security, cloud network security and cloud detection and response across AWS, Azure, GCP, Alibaba Cloud, Oracle Cloud, Kubernetes and on-premises environments. The public CloudGuard REST API - originally Dome9, still served from api.dome9.com and mirrored on the Infinity Portal regional hosts - is documented across 23 first-party OpenAPI definitions covering 823 operations: onboarding cloud accounts, running compliance assessments, managing rulesets and policies, triaging findings, routing notifications, protecting Kubernetes and serverless workloads, and reading a cross-cloud protected-asset inventory. Authentication is HTTP Basic with a V2 API key id and secret created in the CloudGuard portal.

**Areas:** Check Point · CNAPP · Cloud Security · Cloud Security Posture Management · Compliance · CSPM · CWPP · Kubernetes Security · Multi-Cloud · Posture Management · Workload Protection · Dome9

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CloudGuard: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
